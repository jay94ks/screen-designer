# キーボードショートカット＆生産性ガイド (Shortcuts & Productivity)

**Screen Designer** を迅速に操作するためのキーボードショートカットおよびワークフローガイドです。

---

## 1. グローバルショートカット (Global Shortcuts)

| ショートカット | 機能説明 |
| :--- | :--- |
| **`Ctrl + K`** / **`Cmd + K`** | **コマンドパレットを開く** (全コマンド、ツール、ページの検索および実行) |
| **`Ctrl + /`** / **`Cmd + /`** | **キーボードショートカット一覧モーダルを開く** |
| **`Ctrl + Z`** / **`Cmd + Z`** | **元に戻す (Undo)** |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | **やり直し (Redo)** |
| **`Ctrl + S`** / **`Cmd + S`** | **プロジェクト保存 (ディスク即時同期)** |

---

## 2. ツール選択 (Tool Selection)

| キー | ツール | 説明 |
| :---: | :--- | :--- |
| **`V`** | **選択ツール (Select)** | 要素をクリックして選択し、位置やプロパティを編集 |
| **`H`** | **手のひらツール (Hand)** | キャンバスをドラッグして自由にパン移動 |
| **`R`** | **フレーム／長方形 (Rectangle)** | ドラッグして新しいFrameまたはBoxコンテナを追加 |
| **`T`** | **テキスト (Text)** | キャンバスにテキスト要素を配置 |
| **`O`** | **円形／アバター (Circle)** | 円形コンテナまたはアバターを追加 |

---

## 3. キャンバスビュー操作 (Canvas Navigation)

| 操作 / ショートカット | 説明 |
| :--- | :--- |
| **マウスホイール** | キャンバス上下スクロール |
| **`Shift` + マウスホイール** | キャンバス左右スクロール |
| **`Ctrl` + マウスホイール** | マウスポインタ中心のズームイン／ズームアウト |
| **`Space` キーを押しながらドラッグ** | 任意のツールから一時的に手のひら（パン）モードへ切り替え |
| **`Ctrl + 0`** | ズーム倍率を100%にリセット |
| **`Shift + 1`** | 全アートボードが収まるように画面全体にフィット (Fit to Screen) |

---

## 4. 要素の編集＆操作 (Element Manipulation)

| ショートカット | 説明 |
| :--- | :--- |
| **`Ctrl + D`** / **`Cmd + D`** | 選択中の要素を複製 (Duplicate) |
| **`Delete`** / **`Backspace`** | 選択中の要素を削除 |
| **矢印キー (`↑`, `↓`, `←`, `→`)** | 選択中の要素を1px単位で精密移動 |
| **`Shift` + 矢印キー** | 選択中の要素を10px単位で高速移動 |
| **ルーラーのダブルクリック** | ガイドラインを追加 |
| **ガイドラインのダブルクリック** | 対象ガイドラインを削除 |
