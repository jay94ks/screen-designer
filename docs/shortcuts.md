# 키보드 단축키 & 생산성 가이드 (Shortcuts & Productivity)

**Screen Designer**의 빠른 조작을 위한 키보드 단축키 및 워크플로우 안내입니다.

---

## 1. 전역 단축키 (Global Shortcuts)

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + K`** / **`Cmd + K`** | **커맨드 팔레트 열기** (모든 명령, 도구, 페이지 빠른 검색 및 실행) |
| **`Ctrl + /`** / **`Cmd + /`** | **키보드 단축키 모달 열기** |
| **`Ctrl + Z`** / **`Cmd + Z`** | **실행 취소 (Undo)** |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | **다시 실행 (Redo)** |
| **`Ctrl + S`** / **`Cmd + S`** | **프로젝트 저장 (수동 즉시 동기화)** |

---

## 2. 캔버스 도구 선택 (Tool Selection)

| 키 | 도구 | 설명 |
| :---: | :--- | :--- |
| **`V`** | **선택 도구 (Select)** | 요소를 클릭하여 선택하고 위치 및 속성을 편집합니다. |
| **`H`** | **손 도구 (Hand)** | 캔버스를 자유롭게 드래그하여 이동(Pan)합니다. |
| **`R`** | **프레임 / 사각형 (Rectangle)** | 새로운 Frame 또는 Box 요소를 드래그하여 추가합니다. |
| **`T`** | **텍스트 (Text)** | 캔버스에 새로운 텍스트 요소를 삽입합니다. |
| **`O`** | **원형 / 아바타 (Circle)** | 새로운 원형 요소를 추가합니다. |

---

## 3. 캔버스 뷰포트 조작 (Canvas Navigation)

| 동작 / 단축키 | 설명 |
| :--- | :--- |
| **마우스 휠** | 캔버스 상하 스크롤 |
| **`Shift` + 마우스 휠** | 캔버스 좌우 스크롤 |
| **`Ctrl` + 마우스 휠** | 마우스 포인터 중심 확대 / 축소 (Zoom In / Out) |
| **스페이스바 (`Space`) 누른 채 드래그** | 언제든지 일시적으로 손 도구(Pan) 모드로 전환 |
| **`Ctrl + 0`** | 줌 100% 원본 크기 리셋 |
| **`Shift + 1`** | 전체 아트보드가 한눈에 들어오도록 화면 맞춤 (Fit to Screen) |

---

## 4. 요소 편집 및 조작 (Element Manipulation)

| 단축키 | 설명 |
| :--- | :--- |
| **`Ctrl + D`** / **`Cmd + D`** | 선택된 요소 복제 (Duplicate) |
| **`Delete`** / **`Backspace`** | 선택된 요소 삭제 |
| **방향키 (`↑`, `↓`, `←`, `→`)** | 선택된 요소 1px 단위 정밀 이동 |
| **`Shift` + 방향키** | 선택된 요소 10px 단위 빠른 이동 |
| **눈금자 더블클릭** | 가이드라인 추가 |
| **가이드라인 더블클릭** | 해당 가이드라인 삭제 |
