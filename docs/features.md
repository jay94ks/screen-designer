## 1. 헤더 및 윈도우 프레임

- **캡션 바(Caption Bar) & 탑 바(Top Bar) 분리 구조**:
  - **캡션 바 (최상단)**: 네이티브 Electron 타이틀바 역할을 수행하며 프로젝트 브랜딩, 드래그 영역, 창 최소화/최대화/닫기 컨트롤을 포함.
  - **탑 바**:
    - **파일/편집/보기/도움말 메뉴바**: 새 프로젝트, 열기, 저장, 환경설정, 실행취소, 다시실행, 줌 레벨 조정 등.
    - **통합 커맨드 바**: `명령 검색... (Ctrl+K)` 바로가기.
    - **드로잉 & 선택 도구 툴바**: 선택(V), 손 도구(H), 텍스트(T), 프레임/박스(R), 원형(O) 생성 도구.
    - **정렬 툴바**: 좌측, 수평 중앙, 우측, 상단, 수직 중앙, 하단 정렬 및 균등 분배.
    - **플로우 토글 버튼 (`플로우 ●`)**: 프로토타입 연결선 가시성 On/Off 토글.
    - **`▶ PLAY` 버튼**: 실제 모바일 디바이스 목업 프레임에서 인터랙티브 플로우를 체험하는 프레젠테이션 모드 실행.
    - **`디자인 시스템` 독립 버튼**: 컴포넌트별 기본 스타일 및 JSON 스펙을 전폭 화면에서 관리하는 스튜디오 열기.
    - **`Git 브랜치 & 커밋` 상태 배지**: 변경된 파일 개수 실시간 표시 및 내장 Git 데스크톱 모달 호출.

## 2. 무한 캔버스 & 아트보드 관리

- **캔버스 조작**:
  - 휠 줌(Zoom In/Out), 드래그 패닝(Pan), 100% 리셋 및 `Shift+1` 전체 화면 맞춤(Fit).
  - 도트 그리드(Dot Grid) 배경 및 표시 On/Off 토글.
- **눈금자 및 가이드라인 (Canvas Rulers & Guides)**:
  - 상단 가로 눈금자 및 좌측 세로 눈금자 실시간 픽셀 좌표 렌더링.
  - 눈금자에서 캔버스로 드래그하여 수평/수직 가이드라인 자유 추가 및 가이드 더블클릭 제거 지원.
- **다중 아트보드(Artboard / 장표) 워크스페이스**:
  - 장표 상단 툴바: 장표 명칭, 뷰포트 크기, 개별 [이미지 내보내기], [JSON 내보내기], [코드 내보내기], [복제], [삭제].
  - 장표 신규 추가 모달 (`+` 버튼):
    - 빈 캔버스(Blank) 생성
    - **섹션 템플릿 (Section Templates)**: 로그인 화면(Login Form), 실시간 대시보드(Dashboard Stats Grid) 등 원클릭 프리셋 인스턴스화.

## 3. VDOM 요소 트리 및 레이어 관리

- **가상 DOM(VDOM) 컴포넌트 종류**:
  - 컨테이너: `frame`, `card`, `box`, `scroll-container`, `dialog`
  - 텍스트/라벨: `text`, `heading`, `span`, `label`, `blockquote`, `code`
  - 대화형/폼: `button`, `input`, `textarea`, `select`
  - 그래픽/미디어: `image`, `avatar`, `badge`, `icon`, `divider`
- **좌측 레이어 트리 (Left Sidebar)**:
  - 계층형 VDOM 트리 뷰 (들여쓰기 및 접기/펼치기).
  - 레이어 검색 필터 (이름/타입 실시간 검색).
  - 레이어 선택 시 캔버스 내 해당 요소 포커스 및 인스펙터 자동 동기화.
  - 컨텍스트 액션: 요소 복제, 삭제, 순서 변경, 이름 편집.

## 4. 정밀 속성 인스펙터

- **플렉스박스 레이아웃 (Flexbox Layout)**:
  - 가로 방향(Row), 세로 방향(Column) 전환.
  - 주축 정렬 (`justify-start`, `center`, `space-between`, `space-around`, `end`).
  - 교차축 정렬 (`align-start`, `center`, `end`, `stretch`).
  - 아이템 간격(Gap), 패딩(Padding), 마진(Margin) 픽셀 단위 조정.
- **타이포그래피 제어 (Typography)**:
  - 폰트 패밀리 (Inter, Pretendard, System-UI, Serif, Monospace).
  - 폰트 크기(Font Size), 굵기(Weight: 100~900), 줄간격(Line Height), 자간(Letter Spacing).
  - 텍스트 정렬 (좌측, 중앙, 우측, 양쪽 정렬).
- **테두리 및 4모서리 독립 라운딩 (Borders & Corner Radius)**:
  - 전체 반경(Radius) 슬라이더.
  - **4모서리 확장 토글**: 좌상단(Top-Left), 우상단(Top-Right), 우하단(Bottom-Right), 좌하단(Bottom-Left) 독립 수치 입력.
  - 테두리 두께(Border Width), 색상(Border Color), 스타일(Solid, Dashed, Dotted).
- **그림자 (Box Shadow)**:
  - 그림자 프리셋 (`Soft`, `Medium`, `Hard`, `Neon Glow`, `None`).
- **컬러 & 팔레트 스와치 (Colors & Swatches)**:
  - 배경색(BG) / 글자색(Text) 모드 탭 분리.
  - 컬러픽커 및 HEX 코드 직접 입력.
  - **디자인 시스템 스와치 칩 원클릭 적용**: 브랜드 메인, 서브, 다크, 그레이 등 사전 정의된 팔레트 제공.

## 5. 배경 이미지 & 실시간 패턴 제어기

모든 VDOM 컨테이너 및 요소에 배경 이미지, SVG 프리셋, 실시간 그라데이션을 적용할 수 있습니다.

- **원자적 상태 갱신 (`handleBatchStyleChange`)**:
  - 비동기 상태 충돌 없는 안전한 단일 업데이트 파이프라인.
- **로컬 이미지 파일 선택기 (`배경 파일` 버튼)**:
  - 파일 다이얼로그에서 로컬 이미지(PNG, JPG, SVG, WebP) 선택 시, 프로젝트의 `docs/ui-boards/assets/` 폴더로 자동 복사 및 참조.
- **내장 벡터 SVG 프리셋 (Electron Presets)**:
  - 앱에 내장된 고품질 SVG 벡터 프리셋 원클릭 적용:
    - `추상` (오로라 메쉬 그라디언트 SVG)
    - `사이버펑크` (레트로 퓨처리즘 네온 그리드 SVG)
    - `자연` (황혼 산맥 실루엣 풍경 SVG)
- **네온 선형 그라데이션 실시간 제어판 (Linear Neon Controls)**:
  - 360° 회전 각도 슬라이더 및 빠른 각도 칩 (`0°`, `45°`, `90°`, `135°`, `180°`).
  - 시작 색상(Color 1) 및 종료 색상(Color 2) 컬러픽커 + 스톱(0~100%) 슬라이더.
  - 인기 네온 팔레트 프리셋 (오로라 네온, 사이버 핑크, 선셋 오렌지, 일렉트릭 블루 등).
- **다크 메쉬 방사형 그라데이션 실시간 제어판 (Dark Mesh Controls)**:
  - 메쉬 스팟 1 & 2: 독립적인 X좌표(0~100%), Y좌표(0~100%), 확산 반경(Radius 0~100%), 스팟 색상 제어.
  - 베이스 바탕 컬러(Base Color) 지정.
  - 인기 다크 메쉬 프리셋 (인디고 & 퍼플, 사이버 시안 & 핑크, 에메랄드 나이트 등).
- **배경 크기 및 반복 제어**:
  - 크기: `Cover (채우기)`, `Contain (맞춤)`, `Auto (원래 크기)`
  - 반복: `반복 안 함 (no-repeat)`, `바둑판 반복 (repeat)`, `가로 반복 (repeat-x)`
- **원클릭 제거 (`제거` 버튼)**:
  - 설정된 배경 및 잔여 DataURL을 즉시 초기화.

## 6. 피그마 스타일 프로토타이핑 & 와이어

- **시각적 와이어 연결 (Visual Prototype Wires)**:
  - 요소의 이벤트 트리거와 대상 장표(Artboard) 간을 연결하는 3차 베지어 곡선(Cubic Bezier Curve) 오버레이 렌더링.
  - 시작점 펄스 도트 및 도착점 방향 화살표 표시.
  - 상단 `플로우 ●` 버튼을 통해 캔버스 작업 중 언제든지 와이어 가시성 토글 가능.
- **이벤트 인스펙터 (Events Tab)**:
  - 선택된 노드에 인터랙션 이벤트 추가 (`+ 이벤트 추가`).
  - **트리거 유형**: `클릭(Click)`, `우클릭(Right Click)`, `더블클릭(Double Click)`, `마우스 오버(Hover)`.
  - **액션 유형**:
    - **장표 이동 (Navigate)**: 대상 장표 선택.
    - **트윅 값 변경 (Tweak Change)**: 테마 변경, 주문 유형 변경 등 상태 변수 조작.

## 7. 인터랙티브 플레이 모드

- 탑 바의 `▶ PLAY` 버튼 클릭 시 전체 화면 프레젠테이션 모달 실행.
- **디바이스 목업 프레임**: iPhone / Android 스타일 모바일 프레임 내부에서 실제 완성된 앱처럼 작동.
- **인터랙션 핫스팟(Hotspot) 가이드**:
  - 클릭 가능한 이벤트가 바인딩된 요소를 보라색 펄스 아웃라인으로 안내 (`핫스팟 안내` 토글).
  - 버튼 클릭 시 타깃 화면으로 즉시 전환되며, 실제 앱 프로토타입 시연 가능.
- **트윅 컨트롤러 (Tweak Controller)**:
  - 플레이 모드 중에도 하단 트윅 바를 통해 다크/라이트 테마, 통화 단위, 상태 값을 실시간으로 변경하며 화면 변화 검증.

## 8. 디자인 시스템 스튜디오

- 독립 버튼으로 호출되는 전폭(Full-width) 디자인 시스템 관리 인터페이스.
- **기본 스타일(Default Styles) 일괄 정의**:
  - `frame`, `card`, `box`, `button`, `input`, `text`, `heading`, `badge` 등 모든 VDOM 요소의 기본 패딩, 배경색, 글자색, 테두리 반경 등을 설정.
  - 좌측에서 컴포넌트 타입을 선택하면 중앙에 실시간 프리뷰가 표시되고, 우측 속성 패널에서 기본값 편집 가능.
- **자동 저장 및 동기화**:
  - 편집된 디자인 시스템은 프로젝트 관리 폴더의 `docs/ui-boards/design-system.json`에 즉시 반영.
  - 새 요소를 캔버스에 추가할 때 이 디자인 시스템의 기본값이 자동 적용.

## 9. 동적 트윅 & 조건부 렌더링

- **트윅 스키마(Tweaks Schema)**:
  - 화면별 변수 선언: 테마 선택(`theme`: light, dark, cyber), 통화 선택(`currency`: KRW, USD), 주문 유형(`orderType`: 시장가, 지정가), 불리언 토글 스위치.
- **노드별 표시 조건 설정 (Visibility Condition Section)**:
  - 속성 패널 최상단에서 `표시 조건 설정` 스위치 제공.
  - 조건 규칙 빌더: 대상 트윅 변수 선택, 연산자(`equals`, `notEquals`, `contains`), 기준값 설정.
  - 조건에 맞지 않을 경우 캔버스에서는 반투명 경고 테두리로 표시되고, 플레이 모드에서는 완전히 숨김 처리.

## 10. Git 데스크톱 연동

- 탑 바의 `커밋 (N)` 배지 클릭 시 내장 Git 관리 모달 실행.
- **스마트 자동 스테이징 (Smart Auto-Check)**:
  - screen-designer 앱이 관리하는 경로(`docs/ui-boards/`, `.screen-designer/`)의 변경 파일만 기본 체크(Staged) 상태로 표시.
  - 프로젝트 외부의 불필요한 파일이 실수로 커밋되는 것을 원천 차단.
- **간편 커밋 & 고성능 네이티브 Git 엔진 (es-git)**:
  - Toss의 네이티브 libgit2 바인딩 라이브러리인 `es-git`을 채택하여 외부 바이너리 종속 없이 초고속으로 Git 상태 조회, 비주얼 Diff 파싱, 커밋 및 푸시를 실행.
  - 커밋 메시지 입력 후 `커밋 실행` 클릭 시 로컬 커밋 완료 및 Ahead/Behind 브랜치 상태 즉시 동기화.

---

## 11. 내보내기 및 코드 변환

- **장표 헤더의 빠른 내보내기 버튼**:
  1. **[이미지]**: 고해상도 PNG 포맷으로 캡처 및 다운로드.
  2. **[JSON]**: 해당 장표의 VDOM 계층 구조를 규격화된 `.json` 파일로 저장.
  3. **[코드]**: VDOM 구조를 **React 컴포넌트 + Tailwind CSS 클래스** 코드로 자동 컴파일하여 클립보드 복사 및 파일 다운로드.
- **일괄 내보내기 모달 (Export Modal)**:
  - 전체 장표를 한 번에 이미지 ZIP 또는 통합 JSON 구조로 내보내기 지원.

## 12. 커맨드 팔레트 및 단축키

- **커맨드 팔레트 (`Ctrl+K` / `Cmd+K`)**:
  - 페이지 전환, 도구 선택, 모달 열기, 줌 레벨 조정 등 앱 내의 모든 명령어를 키보드 검색으로 즉각 실행.
- **단축키 가이드 (`Ctrl+/`)**:
  - 작업 효율을 극대화하는 키보드 단축키 모음 오버레이.
  - 선택 도구(`V`), 손 도구(`H`), 사각형(`R`), 텍스트(`T`), 타원(`O`), 실행취소(`Ctrl+Z`), 다시실행(`Ctrl+Y`), 줌 인/아웃(`Ctrl + / -`), 전체 맞춤(`Shift+1`).
