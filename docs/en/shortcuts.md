# Keyboard Shortcuts & Productivity Guide

Essential shortcuts and workflow tips for fast operation in **Screen Designer**.

---

## 1. Global Shortcuts

| Shortcut | Description |
| :--- | :--- |
| **`Ctrl + K`** / **`Cmd + K`** | **Open Command Palette** (Quickly search and execute actions, tools, pages) |
| **`Ctrl + /`** / **`Cmd + /`** | **Open Shortcuts Modal** |
| **`Ctrl + Z`** / **`Cmd + Z`** | **Undo** |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | **Redo** |
| **`Ctrl + S`** / **`Cmd + S`** | **Save Project** (Instant disk synchronization) |

---

## 2. Canvas Tool Selection

| Key | Tool | Description |
| :---: | :--- | :--- |
| **`V`** | **Select Tool** | Click to select elements and adjust position / properties |
| **`H`** | **Hand Tool** | Freely drag and pan across the infinite canvas |
| **`R`** | **Frame / Rectangle** | Drag to insert a new Frame or Box container |
| **`T`** | **Text Tool** | Click to place a new Text element |
| **`O`** | **Circle / Avatar** | Insert a circular avatar or container |

---

## 3. Canvas Navigation

| Action / Shortcut | Description |
| :--- | :--- |
| **Mouse Wheel** | Vertical scroll |
| **`Shift` + Mouse Wheel** | Horizontal scroll |
| **`Ctrl` + Mouse Wheel** | Zoom In / Out centered on cursor |
| **Hold `Spacebar` + Drag** | Temporarily activate Hand (Pan) mode from any tool |
| **`Ctrl + 0`** | Reset Zoom to 100% |
| **`Shift + 1`** | Fit all artboards to current screen |

---

## 4. Element Manipulation

| Shortcut | Description |
| :--- | :--- |
| **`Ctrl + D`** / **`Cmd + D`** | Duplicate selected element |
| **`Delete`** / **`Backspace`** | Delete selected element |
| **Arrow Keys (`↑`, `↓`, `←`, `→`)** | Precision move selected element by 1px |
| **`Shift` + Arrow Keys** | Fast move selected element by 10px |
| **Double-click Canvas Ruler** | Add vertical or horizontal guideline |
| **Double-click Guideline** | Remove guideline |
